Method definitions and uncertainty

BM25: lexical baseline with standard length normalisation. Hybrid: BM25 plus character-trigram TF-IDF fused by reciprocal rank. Reranked: the top 12 hybrid candidates reranked using title overlap, coverage, character similarity and fused rank. These are transparent lexical methods.

Protocol and practical limits

  • 48 source passages; 96 authored questions in 36 intent groups. Development and test contain 48 questions each, with no shared intent groups.
  • The source corpus is shared across splits. Gold relevance labels and expected answers never enter retrieval.
  • All methods exclude archived and internal sources and apply the selected plan filter before ranking.
  • Threshold selection utility: correct answers − 4 × incorrect answers − 0.5 × abstained answerable questions.
  • This authored fixture is small and not independently adjudicated. No production, customer-outcome or generalisation claim is supported.

To try arbitrary questions locally: python -m ragbench serve. See the included README for the data contract, tests and client-pilot handover.
